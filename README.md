Write one original line, up to 200 characters, roasting a gadget or app you use every day. A judge model picks the funniest, freshest, neatest line. Free to enter, $5 pot, top 3 paid.

## Run it

```sh
python3 main.py
```

The program writes one line (143 characters) to `/output/entry.txt`:

> My printer only runs out of ink on the morning I actually need it, then spends ten minutes 'cleaning' itself like I'm the one wasting its time.
